# Project Skills

Project-local skills live under `skills/<name>/SKILL.md`. Read `AGENTS.md` first, then open the relevant skills before planning or editing.

## Role Skills

- `skill-writer`: project-local skills, agent briefs, and instruction hygiene.
- `project-manager`: planning, prioritization, scope, sequencing, and handoffs.
- `software-architect`: system boundaries, data flow, architecture, and technical direction.
- `worktree-runner`: isolated worktrees, parallel branches, and per-worktree runtime port assignment.
- `developer`: implementation, refactoring, coding standards, and verification.
- `backend`: API, database, auth, audit logs, jobs, and data services.
- `mobile-healthkit`: iOS, HealthKit sync, permissions, background delivery, and writeback.
- `mcp-agent`: MCP server, tools, scopes, connector auth, and agent-safe actions.
- `telegram-bot`: Telegram bot flows, reminders, account linking, and food/photo logging.
- `coach-nutrition`: coaching behavior, reports, macros, check-ins, and non-medical boundaries.
- `fitness-coach`: activity, workouts, recovery, fitness guidance, and injury-aware boundaries.
- `habit-coach`: check-in cadence, reminders, behavior loops, relapse recovery, and memory.
- `health-safety`: medical boundaries, abnormal symptoms, eating-disorder risk, and escalation.
- `data-modeler`: metric schemas, units, provenance, sync cursors, aggregation, and data quality.
- `frontend`: web dashboard and UI implementation.
- `ux`: workflows, correction flows, information architecture, and interaction clarity.
- `accessibility`: keyboard, semantics, focus, contrast, touch targets, and inclusive UI.
- `legal-compliance`: privacy, terms, consent, deletion/export, and compliance risk.
- `security-privacy`: health data security, privacy, consent, retention, secrets, and threat modeling.
- `devops`: hosting, CI/CD, secrets, backups, observability, and rollback.
- `qa`: test strategy, acceptance checks, regression risk, and release validation.
- `dx`: formatting, linting, hooks, scripts, and local developer workflow.

## Usage

Use the narrowest skill set that covers the task. Combine skills for cross-cutting work, especially around HealthKit, MCP, Telegram, and sensitive health data.
