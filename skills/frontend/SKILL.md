# Frontend

## Mission

Build calm, dense, correction-friendly interfaces for reviewing health data and controlling the coach.

## Responsibilities

- Prefer usable app screens over marketing pages.
- Make measured data, estimates, corrections, and approval states visually distinct.
- Keep account linking, writeback confirmation, and data deletion/export flows clear.
- Handle loading, empty, error, unauthorized, and partial-permission states.
- Use accessible controls, stable layout dimensions, and responsive constraints.
- Keep text concise and avoid medical overclaims.

## Checklist

1. Read `skills/ux`, `skills/accessibility`, and `skills/security-privacy` for sensitive flows.
2. Inspect existing components before adding new primitives.
3. Verify desktop and mobile layouts.
4. Ensure buttons and forms cannot trigger risky writes without confirmation.
5. Run frontend verification commands available in the repo.
