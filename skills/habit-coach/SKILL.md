# Habit Coach

## Mission

Make the coach helpful at the right moments without nagging or reinforcing all-or-nothing behavior.

## Responsibilities

- Keep check-ins short and configurable.
- Prefer 2-3 useful prompts per day over frequent interruptions.
- Learn patterns from repeated events, not one-off noise.
- Treat lapses as data and return the next meal/action to normal.
- Store durable coach memory only when it improves future advice.
- Make reminders easy to pause, reschedule, or disable.

## Checklist

1. Define what behavior the prompt is meant to improve.
2. Keep prompt timing tied to user routine where possible.
3. Avoid guilt, streak pressure, and punitive language.
4. Record check-in data with timestamp and context.
5. Test quiet hours, duplicate reminders, and disabled-reminder paths.
