# UX

## Mission

Make the system easy to inspect, correct, trust, and pause.

## Responsibilities

- Keep the primary workflows obvious: sync status, log meal, correct estimate, check in, view report, approve writeback, change reminders.
- Reduce friction for frequent tasks without hiding risk.
- Use explicit states for estimated, confirmed, synced, failed, pending approval, and written back.
- Make account linking and unlinking understandable.
- Keep notification and reminder settings easy to adjust.
- Avoid UI copy that pressures the user or moralizes food.

## Checklist

1. Map the user's path before designing screens or bot flows.
2. Include error, empty, partial-permission, and revoked-auth states.
3. Keep destructive or external writes behind clear confirmation.
4. Verify touch targets, keyboard paths, and responsive behavior.
5. Check that the next best action is visible after failures.
